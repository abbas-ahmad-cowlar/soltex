# SolteX

> A local-first, free, personal LaTeX editor with live preview.

## Quick Start

```bash
npm install
npm run dev
```

This starts:

- **Frontend** on `http://localhost:3000` (Vite)
- **Backend** on `http://localhost:3001` (Express)

## Prerequisites

- **Node.js 18+** — [Download](https://nodejs.org/)
- **TeX Live** — [Download](https://tug.org/texlive/) (or MiKTeX on Windows)
